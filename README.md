# 主动找你（AstrBot 插件）

角色心里真有事，才主动来找主人。每隔一会儿想一次，大多数时候什么都不发；想到的事有三种去向：**现在说**、**攒着等主人来了再说**、**不说**。需要先装[记忆核心](https://github.com/JikunLiu101/astrbot_plugin_memory_core)（memory-core）插件（状态和记忆都存在它的记忆目录里）。

## 四种念头

| 念头 | 什么时候有 |
|---|---|
| 做错的事 | 别的插件报告做错了、影响到主人的（`report_mistake`） |
| 惦记 | 主人说过带日期的计划，到了那天晚上还不知道结果，问一次 |
| 分享 | 上网后还没考虑过的感想 |
| 想念 | 分开久了，按概率；一次分开只说一次 |

模型一次判断所有念头说不说；分享按五项打分（和主人有关、她的反应、时效、新不新、能不能接话），高分才打扰。最后由代码把关：做错且影响主人的一定说；一次最多发一条（做错 > 惦记 > 分享 > 想念），其余攒着。

## 节制规则（都由代码执行）

- 只发给主人、只发私聊、只在“可以发消息的平台”里，发到主人最后说话的那个私聊；从不发到群里。
- 主人刚刚还在说话时不发；她睡着时（按 memory-core 的作息）只说影响主人的错。
- 每天最多几次、两次之间至少隔多久、连着几条没回就停（直到主人再说话），都在设置里。
- 发之前停一会儿像在打字，一行一条发出；发出的话记进她的经历，也补进 AstrBot 的会话历史。
- 默认拿掉 AstrBot 自带的 `send_message_to_user`、`future_task`，她只能通过这里主动说话。

## 主人回来时

攒着的话（2 天内）附在主人这句话后面告诉她，每条只在一次来访里给一次。

## 她能用的工具

`thoughts_recall`：回想最近想过什么、当时为什么说或没说（只在主人私聊里）。

## 主人的命令

只对主人、只在私聊、只在本机网页对话里有效。

| 命令 | 作用 |
|---|---|
| `/tov_log` | 看她最近想过什么、怎么决定的 |
| `/tov_think` | 试想一次（不管时间规则，不发送，不改状态） |

## 给其他插件

做错事时调用 `report_mistake(what, severity, affects_owner)`，她会按上面的规则决定要不要告诉主人。

## 后台面板

AstrBot 4.24.2 起，后台「插件 → 主动找你 → 视图 → 心事」：今天主动说了几次、连着几条没回、下次最早什么时候；
最近的念头（想念、分享、惦记、做错）和去向——说了、攒着还是没说，为什么，模型原本想怎样、规则有没有改；
攒着等主人来了再说的话；她主动发出的消息和主人回没回。“试想一次”和 `/tov_think` 一样，不发消息、不改动什么；
“都不说了”放下所有攒着的话。

## 支持的平台

只用 AstrBot 的通用消息事件，不依赖哪个平台独有的功能。需要的是：私聊里认得出谁是主人，并且平台允许机器人**主动**给对方发私聊消息（QQ 官方机器人、微信公众号这类限制主动消息的平台不合适，所以没列）。元数据里列的是满足这些的主流平台：Telegram、QQ（OneBot / aiocqhttp）、Discord、KOOK、飞书、钉钉、企业微信、Slack。**实际测过的只有 Telegram 和 AstrBot 自带的网页对话**，其他平台欢迎反馈。需要 AstrBot 4.24.2 及以上。

## 借鉴

思路参考了 Inner Thoughts 论文（[Proactive Conversational Agents with Inner Thoughts](https://arxiv.org/abs/2501.00383)：先产生念头、再打分决定说不说）和 [astrbot_plugin_proactive_chat](https://github.com/DBJD-CR/astrbot_plugin_proactive_chat)（安静时段、连着没回就停；AGPL，只借思路，没有用它的代码）。
